# Brief image principale — SEO-001 v3

## Objectif

Illustrer clairement le changement de caisse maladie en Suisse et
l'importance du calendrier, sans représenter ni favoriser une compagnie
précise.

## Concept recommandé

Une composition professionnelle et réaliste comprenant :

- un calendrier mettant visuellement en évidence le 30 novembre ;
- une enveloppe ou une lettre de résiliation ;
- un environnement administratif suisse sobre ;
- aucun logo d'assureur ;
- aucun logo officiel de l'OFSP ou de la Confédération ;
- aucune carte d'assurance comportant des données personnelles ;
- aucune donnée médicale ;
- aucune promesse d'économie ;
- aucune personne reconnaissable nécessaire.

## Style

- professionnel ;
- moderne ;
- rassurant ;
- neutre ;
- adapté à un cabinet de conseil suisse ;
- compatible avec le style visuel de Legrand Conseils.

## Format recommandé

À contrôler ultérieurement dans WordPress, selon les dimensions réellement
imposées par le thème Kadence (non documentées dans ce dépôt) :

- image principale horizontale ;
- variante Open Graph ;
- variante mobile si nécessaire.

Aucune dimension n'est imposée ici — les dimensions du thème Kadence
devront être vérifiées directement dans WordPress avant production finale.

## Nom de fichier recommandé

changer-caisse-maladie-delais-etapes.webp

## Texte alternatif recommandé

Calendrier et lettre de résiliation pour changer de caisse maladie en Suisse

## Légende proposée

Le délai de résiliation pour changer d'assureur est fixé au 30 novembre.

## Contrôles avant utilisation

- droits d'utilisation ;
- absence de logo protégé ;
- absence de données personnelles ;
- compression ;
- poids du fichier ;
- rendu mobile ;
- cohérence avec l'identité visuelle ;
- validation humaine finale de l'image.

Aucune image n'a été générée ni téléchargée durant cette phase.
