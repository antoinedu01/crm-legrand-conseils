# Checklist de publication — SEO-001 v3

Checklist dédiée, dérivée de
`marketing-ai/templates/checklist-finale-avant-publication.md` et de
`marketing-ai/templates/content-validation-template.md` (non modifiés par ce
document). Aucune publication n'est autorisée tant que tous les points
bloquants ne sont pas cochés et que la décision de publication n'a pas été
donnée explicitement par un humain.

---

## Validation éditoriale

- [ ] version source v3 confirmée comme version publiée
- [ ] SEO validé (`seo_review` = validé)
- [ ] conformité validée (`compliance_review` = validé)
- [ ] validation humaine validée (`validation_humaine` = validé, validateur et date renseignés)
- [ ] contenu public extrait sans sections internes
- [ ] aucune modification de fond non validée depuis la dernière review

## WordPress

- [ ] brouillon réellement créé dans WordPress
- [ ] titre saisi séparément dans le champ titre (devient le H1)
- [ ] absence de H1 dupliqué dans le corps de l'article
- [ ] slug contrôlé et disponibilité vérifiée
- [ ] catégorie contrôlée
- [ ] auteur contrôlé
- [ ] statut WordPress = brouillon
- [ ] URL de prévisualisation enregistrée seulement après création réelle

## Rank Math

- [ ] title SEO
- [ ] méta-description
- [ ] mot-clé principal
- [ ] aperçu ordinateur
- [ ] aperçu mobile
- [ ] index/noindex
- [ ] URL canonique
- [ ] Open Graph
- [ ] Twitter/X Card si disponible

## Maillage

- [ ] URL page LAMal confirmée
- [ ] URL page complémentaires confirmée
- [ ] URL page contact confirmée
- [ ] SEO-003 publié avant activation du lien
- [ ] SEO-005 publié avant activation du lien
- [ ] aucun lien cassé
- [ ] liens externes officiels contrôlés

## FAQ et schéma

- [ ] FAQ visible correctement dans le rendu WordPress
- [ ] présence ou absence de schéma FAQPage généré automatiquement vérifiée
- [ ] aucun double balisage FAQPage
- [ ] test de données structurées prévu après publication

## Image

- [ ] image créée ou sourcée légalement
- [ ] droits vérifiés
- [ ] nom de fichier optimisé
- [ ] texte alternatif renseigné
- [ ] compression contrôlée
- [ ] rendu mobile contrôlé
- [ ] Open Graph contrôlé

## Formulaire et CTA

- [ ] CTA lisible
- [ ] URL de contact confirmée
- [ ] formulaire fonctionnel
- [ ] consentement explicite contrôlé sur la page de destination
- [ ] aucune donnée médicale demandée
- [ ] aucune publication ou envoi automatique non validé

## Contrôle final

- [ ] ordinateur
- [ ] mobile
- [ ] tablette si possible
- [ ] orthographe
- [ ] liens
- [ ] sources
- [ ] absence de contenu interne
- [ ] date de publication laissée vide avant publication
- [ ] URL publique définitive laissée vide avant publication
- [ ] publication uniquement après décision humaine explicite
